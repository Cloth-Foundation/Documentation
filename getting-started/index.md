# Getting started

Start with a working program, then learn the rules that make larger Cloth
programs readable.

1. [Hello World](/docs/getting-started/hello-world) creates a project and runs it.
2. [Language basics](/docs/getting-started/language-basics) introduces variables,
   functions, arrays, and loops.
3. [Working with types](/docs/getting-started/working-with-types) adds a class,
   an import, and a nullable value.

These tutorials assume the [toolchain is installed](/docs/installation) and
`clothc` and `shuttle` are available in your terminal. You do not need a standard
library for these programs: `string`, arrays, and `println` are built into Cloth.
