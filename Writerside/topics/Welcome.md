# Welcome

## What is Cloth?
Cloth is a statically typed, object-oriented programming language. The main philosophy behind Cloth is to be simple and easy to learn,
while still being powerful enough to be used in real-world projects. The language is still in its infancy, but it is already usable.

## Why Cloth?
Cloth is a great language for learning and experimenting with new ideas. It is also a great language for writing production-quality code.
The design of Cloth is heavily inspired by Java, C++, and Go. The Cloth compiler, while written in Go (gCloth), is being actively adapted
such the Cloth can dogfood itself.
