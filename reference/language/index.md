# Language rules

Start with [source files and syntax](/docs/reference/language/syntax), then
[variables](/docs/reference/language/variables-and-visibility),
[functions](/docs/reference/language/functions), and
[control flow](/docs/reference/language/control-flow).

For data modeling, read [classes](/docs/reference/language/classes),
[inheritance](/docs/reference/language/inheritance), and
[interfaces](/docs/reference/language/interfaces). Value types have their own
reference pages: [enums](/docs/reference/types/enums) and
[structs](/docs/reference/types/structs).

[Packages and imports](/docs/reference/language/modules-and-imports) explains
how types in separate files become available. [Nullability](/docs/reference/language/nullable)
and [conversions](/docs/reference/language/casts) explain how values move between
compatible types.

Use [operators](/docs/reference/language/operators),
[meta operations](/docs/reference/language/meta-operations),
[binary data](/docs/reference/language/binary-data), and
[printing](/docs/reference/language/printing) as lookup pages.
[Memory and runtime failures](/docs/reference/language/memory-and-errors)
describes lifetime management and checked failures.
